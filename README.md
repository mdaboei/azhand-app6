# آژند اپ — سورس کامل (شرکت آژند همت توس)

این بسته سورس کامل برنامه (بخش وب + اندروید) است.

## ساختار بسته گیت‌هاب
- `ajand-source.zip` — کل سورس پروژه
- `.github/workflows/build-apk.yml` — بیلد خودکار APK

## مراحل آپلود در گیت‌هاب (فقط ۳ فایل!)
1. یک ریپازیتوری **New** بسازید (Private توصیه می‌شود).
2. در صفحه آپلود، این سه مورد را بکشید و رها کنید:
   - `ajand-source.zip`
   - پوشه `.github` (شامل workflows)
   - `README.md`
3. روی **Commit changes** بزنید. بیلد خودکار شروع می‌شود.
4. بعد از اتمام (۳ تا ۶ دقیقه)، از تب **Actions** → بیلد سبز →
   قسمت **Artifacts** فایل `ajand-app-apk` را دانلود کنید.
5. داخل فایل دانلودی، `app-debug.apk` روی گوشی نصب کنید.

> 💡 اگر بیلد خودکار شروع نشد: تب Actions → Build Android APK → Run workflow

## آپدیت بدون حذف اپ (مهم!)
- شناسه برنامه `com.karlist.app` است و **نباید** تغییر کند؛
  تا APK جدید بدون حذف نسخه قبلی نصب شود.
- فقط فایل `ajand-source.zip` جدید را در ریپو Replace کنید و
  دوباره workflow را اجرا کنید.
- ⚠️ یک‌بار ضروری: اگر بیلد با خطای `Could not read package.json` شکست خورد،
  فایل `.github/workflows/build-apk.yml` را هم از این بسته Replace کنید —
  نسخهٔ جدید مرحلهٔ «استخراج سورس» دارد که `ajand-source.zip` را در ریپو باز می‌کند.

## اجرای سرور (ویندوز)
بستهٔ جداگانه `ajand-windows-server.zip` را داخل شرکت باز کنید و
`start-server.bat` را اجرا کنید.
